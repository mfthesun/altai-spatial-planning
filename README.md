# Республика Алтай — концепция пространственного развития

Курсовой проект по дисциплине «Пространственное планирование». Магистратура «Цифровая урбанистика», ИДУ ИТМО. Команда «Приморск».

Цель — концепция пространственного развития Республики Алтай на горизонтах 2035/2050.

**Репозиторий открыт: подключиться может любой участник — см. [CONTRIBUTING.md](CONTRIBUTING.md). Задачи команды — в [Issues](https://github.com/mfthesun/altai-spatial-planning/issues).**

[![Открыть в Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/mfthesun/altai-spatial-planning) [![Открыть блокнот в Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/mfthesun/altai-spatial-planning/blob/main/relief/altai_access_mountain.ipynb) Методика курса: диагностика → SWOT → доктрина → ТЭЗ → каркасы и узлы → мероприятия → флагманские проекты.

## Структура

| Путь | Что внутри |
|---|---|
| `docs/altai_context.md` | Сводный контекст по региону: экономика, расселение, туризм, инфраструктура, источники |
| `docs/altai_stp_2026.md` | Конспект СТП Республики Алтай (постановление № 357 от 11.09.2026) |
| `docs/data_catalog.md`, `docs/validation_report.md` | Каталог данных и отчёт о проверке сводного датасета |
| `data/dataset_v3/` | Сводный датасет по 11 МО: сводка, длинная панель, 247 НП, точечные слои (МСП, ДТП, пожары, МКД) |
| `data/dataset_v4/`, `docs/validation_ndfl.md` | v3 + налоговая отчётность ФНС по НДФЛ: районы 2022–2025, сравнение с Тывой и Хакасией 2016–2025 |
| `scripts/dataset/` | Сборка датасета из архивов «Если быть точным» (БД ПМО Росстата и др.) |
| `data/access_inputs/`, `docs/access_inputs.md` | Входные слои для расчёта доступности больниц и обеспеченности ими: граница, НП со спросом, 11 больниц, точки изохрон |
| `scripts/access/` | Сборка этих слоёв |
| `relief/`, `docs/relief_method.md` | Поправка времени в пути на горный рельеф (Copernicus DEM GLO-30) и блокнот Colab: граф → OD-матрица → обеспеченность → изохроны |
| `data/access_results/`, `docs/access_results.md` | Результаты расчёта доступности больниц: доли жителей в нормативе по МО, время по НП, изохроны, карты PNG |
| `data/stp_extracted/` | Из текста СТП (docx): реестр объектов культурного наследия по районам, таблицы природных рисков |
| `data/onp_candidates.csv`, `docs/closed_tasks_2026-10-28.md` | Кандидаты в опорные населённые пункты; закрытые задачи: базовая характеристика, Стратегия 2035, энергобаланс, дороги, турпоток |
| `data/raw/README.md` | Какие сырые архивы нужны и откуда их взять. Сами архивы в репозиторий не входят |

## Быстрый старт

```bash
pip install -r requirements.txt
# доступность больниц с учётом рельефа — в Google Colab:
#   relief/altai_access_mountain.ipynb (укажите путь к репозиторию в REPO)
# пересборка датасета — нужны сырые архивы в data/raw (см. data/raw/README.md):
python scripts/dataset/build_dataset.py && python scripts/dataset/export.py
python scripts/access/build_access_inputs.py
python scripts/access/make_access_maps.py   # карты и таблицы по results/ блокнота
```

Пути переопределяются переменными окружения:

| Переменная | Что задаёт |
|---|---|
| `ALTAI_RAW` | Папка с распакованными архивами |
| `ALTAI_SOURCES` | Папка с исходными PDF |
| `ALTAI_OUT` | Папка для результатов сборки |

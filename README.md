# Республика Алтай — концепция пространственного развития

Курсовой проект по дисциплине «Пространственное планирование». Магистратура «Цифровая урбанистика», ИДУ ИТМО. Команда «Приморск».

Цель — концепция пространственного развития Республики Алтай на горизонтах 2035/2050.

Этап концепции завершен 13.11.2026: **22 слайда основного показа и 15 скрытых резервных**, задачи №1–8 закрыты с отчетами. [Результат и границы приемки](docs/issue_closure_2026-11-13.md) · [Презентация и проверки](docs/final_presentation_2026-11-13.md) · [Проверка 20 карт](docs/map_visual_audit_2026-11-13.md).

**Репозиторий открыт: подключиться может любой участник — см. [CONTRIBUTING.md](CONTRIBUTING.md). Задачи команды — в [Issues](https://github.com/mfthesun/altai-spatial-planning/issues).**

## Проверка готовых данных

Команды выполняются из корня репозитория в окружении с зависимостями из `requirements.txt`.
Проверено в существующем окружении Python 3.12.15. Если окружения еще нет,
пример ниже предполагает доступный интерпретатор `python3.12`:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Проверки используют включенные в Git данные; загружать граф дорог и сырые архивы для них не нужно:

```bash
python scripts/check_numbers.py
python scripts/check_map_context.py
sha256sum -c assets/fonts/SHA256SUMS
```

Числовая проверка охватывает 102 показателя из файлов проекта, а не все тексты Figma
и внешние источники. Отрицательный контроль `python scripts/check_numbers.py --control`
должен найти одно расхождение и завершиться с кодом 1.

## Пересборка

[Инструкция по воспроизведению](docs/reproduction.md) разделяет экспорт карт из готовых
данных и полный пересчет. Экспорт записывает PNG и требует доступа к тайлам Esri;
полная сборка требует внешних архивов, графа и OD-матриц. Они не входят в клон.
Блокнот для локального запуска и Colab — [relief/altai_access_mountain.ipynb](relief/altai_access_mountain.ipynb).

## Статус и ограничения

[PR №26](https://github.com/mfthesun/altai-spatial-planning/pull/26) слит в main;
восемь задач этапа закрыты с отдельными отчетами.
Актуальные [результаты и ограничения по каждой задаче](docs/issue_closure_2026-11-13.md)
важнее исторической [матрицы 04.11](docs/project_status_2026-11-04.md).
Снимки предыдущих этапов сохранены в `docs/` и истории Git.

Закрытие этапа не означает завершения всех исследований: остаются ограничения
адресных привязок, обоснования природной емкости, охранных зон, кадров и мощностей,
стоимости и операторов проектов. Маршрут наследия — предварительное предложение;
медицинские эффекты — результаты географических сценариев.
Историческая оценка ФАПов по отмененному № 543н не является актуальным перечнем строительства.

Служебные резервные копии исключены из текущего дерева; порядок восстановления
и объем очистки — в [отчете об обслуживании репозитория](docs/repository_maintenance_2026-11-13.md).

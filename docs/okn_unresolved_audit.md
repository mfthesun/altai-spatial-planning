# Разбор 121 ОКН без координат — 10.11.2026

Построчный результат — [CSV](../data/okn/egrokn_altai_unresolved_audit.csv).
В нем сохранены исходные адрес и район, группа проблемы, следующее действие,
полное название из СТП и документы охраны. Исходные CSV и геометрия не изменены.

названиям выгрузки и СТП. Наличие топонима не подтверждает местоположение
или уникальность. Кавычки у слов «керексуры» и «усы» не считаются именной
подсказкой. Для пяти комплексов подсказки найдены только в полном названии СТП.

## Очередность дальнейшей работы

1. Восстановить адрес дома Бодунова и район группы курганов по номеру,
   отдельно подтвердить идентичность «Кызыл-Телань-1».
2. Для трех непустых адресов искать территории объектов в документах охраны.
3. Для 51 объекта с именными подсказками искать карточки и акты по
   регистрационному номеру, затем сверять название и район. Среди них
   Калбак-Таш, Пазырыкская группа, Улалинская стоянка и комплекс Юстыд.
4. Для 66 объектов с общими названиями начинать с регистрационного и
   учетного номеров. Названия «Группа курганов» или «Каменное изваяние»
   недостаточны для выбора точки. Проверять ансамбли и входящие памятники
   отдельно, даже если их территории пересекаются.

Для всех групп координаты можно принимать только вместе с основанием
и уровнем точности. Совпадение названия с селом дает ориентир для поиска,
а не координаты памятника.

## Воспроизведение и пределы проверки

`python scripts/okn/audit_unresolved.py` создает таблицу из локальных файлов.
Самопроверки контролируют 121 уникальный номер, полный охват уровня X,
три непустых адреса и найденные сведения по дому Бодунова и двум районам.
Новых зависимостей нет.

При повторной проверке исправлена первоначальная группировка 47/70.
Две записи с кавычками вокруг общих терминов перенесены в общие названия.
В именную группу добавлены пещера Иульчак и пять комплексов, названия которых
раскрыты в СТП. Проверка всех 121 строк по исходной вырезке ЕГРОКН подтвердила
сохранность названий и адресов. Сопоставления СТП независимо проверены по
15-значным номерам с границами числа, а для «Кызыл-Телань-1» — по названию.

Внешние карточки, акты и координаты не проверялись. Достоверность записей
уровней A и B в эту проверку не входит. Число объектов с координатами остается
167 из 288.

Продолжение от 11.11.2026: выполнено [пробное сопоставление с OSM](okn_osm_matching.md).
Четыре объекта имеют кандидатов по имени и району. Они пока не приняты в основной слой.

После [проверки первоисточников](okn_geocoding_verification.md) создан отдельный
рабочий слой со 170 точками. Три привязки из исходного остатка добавлены с
маркировкой происхождения и точности. Этот аудит по-прежнему описывает
исторический набор из 121 записи, исходная таблица не перезаписана.

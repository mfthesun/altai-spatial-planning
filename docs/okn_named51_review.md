# Индивидуальная проверка 51 ОКН — 11.11.2026

Проверена группа из 51 объекта с именными или топонимическими подсказками
из исходного аудита 121 записи. По каждому выполнены два отдельных запроса:
по 15-значному номеру и по названию. Для всех сверена запись официального
перечня инспекции. Для 37 дополнительно прочитаны связанные первоисточники,
для 14 пригодный дополнительный текст или привязка не подтверждены.

Это законченный индивидуальный поисковый проход, а не исчерпывающая проверка
всех архивов. Отсутствие результата в нем не доказывает отсутствие данных.
У каждой строки указан фактический уровень проверки. Ссылка из поисковой
выдачи не засчитывается как прочитанный документ.

- [Построчная таблица 51 объекта](../data/okn/named51_review.csv): запросы,
  источники, страницы, выводы, исходная запись координат и дальнейшее действие.
- [Журнал 102 запросов и URL выдачи](../data/okn/named51_search_log.json).
- [Ручные результаты проверки](../data/okn/named51_findings.csv), из которых
  пересобираются сводные таблицы.
- [Обновленная проверка всех 121 записей](../data/okn/okn_source_checks.csv).

## Координаты, которые не добавлены

В [научном своде афанасьевских памятников](https://www.old.archeo.ru/izdaniya-1/vagnejshije-izdanija/pdf/SvodAfanas2014.pdf)
найдены измерения для Ело-Баши, Нижнего Тюмечина-1 и Первого Межелика-1.
Сохранены все прочитанные пары, включая точки отдельных частей могильников
и раскопа. В своде нет наших реестровых номеров, поэтому совпадение названия
пока не превращено в принятую реестровую привязку. Первый Межелик-1 возле Ело
не подменен одноименным объектом Кош-Агачского района.

В исторической таблице Чемальского района обнаружены следующие проблемы:

- Айрыдаш и Кызыл-Телань-1: неоднозначно оформленные минуты и секунды,
  в том числе трехзначные значения после знака секунд. Формат молча не исправлялся.
- Кара-Турук: у долгот минуты 99.422–99.639. Такие координаты не приняты.
- Кара-Тенеш: численно читаемые пары требуют сверки с независимым планом
  и описанием местности, поэтому пока не включены.

Для ансамбля Юстыд муниципальный перечень дает одну пару координат,
но она требует проверки положения. Эта пара не размножена на Юстыд-12,
Юстыд-13, стоянку и другие входящие объекты. Для Юстыда-13 найден отдельный
относительный ориентир, для стоянки Юстыд — описание пойменного положения.

Кызыл-Телань-1 теперь подтвержден в дополнительном документе по точному
реестровому номеру. Прежнее предварительное соответствие только по названию
уточнено, но проблема формата координат осталась.

## Пазырык: проверка приложений

[Акт Пазырыка](https://okn-ra.ru/attachments/article/57/%D0%90%D0%BA%D1%82%20%D0%9F%D0%B0%D0%B7%D1%8B%D1%80%D1%8B%D0%BA.pdf)
подтверждает номер ОКН на с. 5. В приложении на с. 25–28 находится выписка
на природный парк «Ак Чолушпа», а не территория археологического ОКН.
Эта геометрия для памятника не использована.

Нужные схема и таблицы территории ОКН находятся на с. 33–34. Перенесены
20 вершин трех раздельных контуров:
[исходная таблица](../data/okn/pazyryk_boundary_source.csv).
Проверенные площади — 81 497.77, 74.09 и 30 464.63 м², расхождения
с округленными площадями документа меньше 1 м² для каждого контура.

В заголовке таблицы написана МСК-04, зона 1, при этом восточные координаты
имеют значения около 2 272 000 м. Обозначение зоны противоречит ожидаемому
диапазону используемых параметров. Исходная подпись сохранена, преобразование
в WGS-84 и автоматическая замена зоны не выполнены. Для продолжения нужно
подтверждение системы координат исходного документа.

## Что именно воспроизводится

Ручные выводы и прочитанные координаты хранятся в `named51_findings.csv`.
`python scripts/okn/summarize_evidence.py` объединяет их с журналом запросов
и источниками, проверяет полный охват 51 уникального номера и пересобирает
`named51_review.csv` и общую таблицу 121 записи. Сам веб-поиск эта команда
повторно не выполняет.

`python scripts/okn/build_verified_geocoding.py` собирает рабочий слой.
`python scripts/okn/verify_evidence_geometry.py` проверяет пересчет новых
координат, районы, сохранность спорных случаев вне рабочего слоя и площади
контуров Пазырыка. Для текущей установки pyproj используется
`$env:PYTHONPATH = 'tmp/okn-tools'`.

Полные PDF источников остаются локальными по правилу `*.pdf`, URL и SHA-256
есть в [описи](../data/okn/evidence_inventory.csv). Страница Минкульта
`maps/show/id/1909008` вернула форму входа и источником содержания не признана.
Копия указа на сайте музея вернула 404. Монография по истории палеолита
на старом домене АлтГУ не скачалась из-за сертификата. Поисковые фрагменты
этих ресурсов не выдаются за прочитанные документы.

Исторические A/B/X, старые карты и презентация не перезаписаны.
150 оставшихся приказов из прежнего индекса этим проходом не просмотрены.

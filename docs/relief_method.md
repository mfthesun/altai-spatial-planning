# Поправка доступности на горный рельеф (Республика Алтай)

## Проблема
Граф IduEdu (`get_drive_graph`) считает время только по длине и классу дороги:
- trunk — 90 км/ч;
- primary, secondary, tertiary — 60 км/ч;
- unclassified — 40 км/ч.

Подъёмы, серпантины и грунтовое покрытие не учитываются. Кроме того, стандартный фильтр `drive` **исключает `highway=track`**, а в горах на таких дорогах держится часть подъездов к сёлам. В результате изохроны на юге и востоке республики получаются завышенными, а часть сёл может оказаться недостижимой.

## Решение
Методический источник — курс Т. Балтыжаковой «Пространственный анализ урбанизированных территорий» (ИДУ ИТМО):
- раздел «Анализ рельефа»: ЦМР SRTM, FABDEM, GEDTM30, расчёт уклонов;
- раздел «Загрузка данных ДЗЗ»: открытые спутниковые архивы.

Отличие нашего способа в том, что ЦМР не обрабатывается в QGIS, а «натягивается» на рёбра графа скриптом.

**1. Спутниковая ЦМР — Copernicus DEM GLO-30.**
- Радарная съёмка TanDEM-X, разрешение 30 м.
- Открытый бакет AWS `copernicus-dem-30m`, регистрация не нужна.
- Нужные тайлы (около 30 шт.) скрипт сам скачивает в Colab.
- Почему не другие ЦМР:
  - SRTM требует аккаунт USGS;
  - FABDEM лучше в лесу, но распространяется архивами 10°×10° на несколько ГБ;
  - любую из них можно подставить вместо Copernicus.

**2. По каждому ребру графа — точки через 25 м.** Для них считаются:
- высота: сглаживается медианой по 125 м, чтобы убрать шум от леса — Copernicus является моделью поверхности (DSM);
- уклон на базе 100 м;
- радиус кривой по трём точкам с шагом 50 м.

**3. Скорость на каждом отрезке:** `v = min(v_класса/покрытия, v_кривой) × k_уклона`.

| Составляющая | Как задаётся |
|---|---|
| Кривая | `v_кривой = √(127·R·(μ + i))` — формула устойчивости на кривой, `R = V²/127(μ+i)`; μ = 0,15, вираж 0,02. Примеры: R = 30 м → 25 км/ч; R = 100 м → 46 км/ч; R = 300 м → 80 км/ч |
| Покрытие | Потолок скорости: гравий — 45, unpaved — 35, грунт — 25 км/ч; track: grade1–4 — 45/35/25/15 км/ч |
| Подъём | Штраф сверх 4 %: 9 % → −20 % скорости, не более −50 % |
| Спуск | Штраф сверх 6 %: не более −40 % |

**4. Время ребра** — сумма по отрезкам. Для двусторонних рёбер берётся среднее «туда/обратно», потому что UrbanGraph хранит один вес на ребро. Исходное время сохраняется в `time_min_flat`.

**5. Калибровка.**
- В `calibration_pairs.csv` 11 пар «больница — больница» со ссылками на маршруты Яндекса.
- Нужно заполнить `ref_min` — время без пробок — и посмотреть медианное отношение «эталон / модель».
- Подъём, спуск и покрытие — **экспертные допущения**, их нужно проверить именно калибровкой.

## Файлы
| Файл | Что это |
|---|---|
| `mountain_speed.py` | Модуль: `DRIVE_WITH_TRACKS` (фильтр с track), `adjust_graph()`, `calibrate()`, `PARAMS` (все коэффициенты) |
| `altai_access_mountain.ipynb` | Colab, полный конвейер: граф → рельеф → калибровка → OD → обеспеченность А/Б → сравнение «плоский / горный» → изохроны → zip |
| `calibration_pairs.csv` | Пары для калибровки, столбец `ref_min` — заполнить |

**Порядок работы:** загрузить файлы на Google Drive вместе с содержимым «Входные_данные_доступность», указать путь в `INPUT_DIR`, запустить ячейки по порядку.

**Время работы:**
- граф по всей территории — около 5–15 мин (Overpass);
- рельеф — около 10 мин: скачивание тайлов (~1 ГБ) и обработка рёбер.

## Проверено
- Модуль протестирован на синтетическом графе и синтетической ЦМР:
  - прямая дорога — 60 км/ч, без изменений;
  - серпантин, подъём 6 %, R ≈ 26 м — 33 км/ч;
  - прямой подъём 9 % по гравию — 32 км/ч.
- Ячейки OD-матрицы, обеспеченности, сравнения и изохрон прогнаны на реальных слоях.
- **На реальном графе Алтая не запускалось.** Overpass и AWS недоступны из моей среды; в Colab доступ к ним есть.

## Ограничения
- Copernicus — модель поверхности: в лесу высота завышена на высоту крон. Медианное сглаживание это частично гасит; FABDEM — более точная альтернатива.
- Сезонность не учтена: снег, перевал Кату-Ярык, переправы. При необходимости можно добавить снежный покров MODIS как сезонный сценарий.
- Покрытие берётся из тегов OSM (`surface`, `tracktype`); там, где тег не заполнен, используется скорость по классу дороги.

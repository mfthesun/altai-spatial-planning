## Метод и ограничения

Сопоставление использует название выгрузки и полное название СТП. Общие
слова и части топонимов вроде «курган», «памятник», «Усть», «Кара», «Таш»
исключаются из именных подсказок. Поиск ориентирован на русские названия,
их альтернативные формы и описания в тегах. Транслитерация, нечеткий поиск
и восстановление по близости к селам не выполнялись.

Район точки определен по `data/slides/layers/mo_boundaries.geojson`.
Для линий и отношений используется центр ограничивающего прямоугольника
из ответа Overpass. Он нужен для предварительной проверки района и не
описывает территорию ОКН. Исходная геометрия OSM этим запросом не загружена.
Вблизи границ районов результат нужно проверять по полной геометрии.

Ни один кандидат не перенесен в основной слой. Для четырех кандидатов
нужна проверка карточки или акта по регистрационному номеру и сравнение
описания территории. Для дома Бодунова сначала требуется разрешить
расхождение адресов. Документы охраны при этом запуске не открывались.

## Воспроизведение

`python scripts/okn/match_osm.py` использует сохраненный ответ и пересоздает
две таблицы. Без сохраненного ответа выполняет GET-запрос к основному серверу
Overpass, адрес можно переопределить через `OVERPASS_URL`.
Mail.ru вернул 504, Kumi не ответил за время ожидания. Основной сервер
`overpass-api.de` успешно вернул выборку.

Скрипт использует стандартную библиотеку Python. Самопроверки проверяют
исключение общих слов и ложных совпадений «Кара-Бога» / «Кара-Бом»,
«Усть-Майма» / «Усть-Каракол», определение попадания точки в кольцо,
полноту сводки и отсутствие повторных пар.

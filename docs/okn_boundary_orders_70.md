# Приказы о границах для 70 объектов без адресной привязки

Состояние на 12.11.2026. Выполнен первый автоматический этап плана: каталог
приказов Инспекции Республики Алтай скачан и проверен на наличие текстового
слоя и номеров.

## Что сделано

- В каталоге найдено **153 PDF-ссылки** из раздела «Границы территории ОКН».
- Скачаны все **153 PDF**.
- Всего в них **964 страницы**.
- Извлеченный текст содержит **0 русских букв**: документы являются сканами.
- Автоматическое сопоставление по 15-значным реестровым номерам и старым
  учетным номерам дало **0 совпадений**.
- В рабочий геослой координаты не добавлялись.

Таким образом, отсутствие совпадений означает отсутствие текстового слоя, а не
отсутствие объектов в приказах. Номера и координаты находятся на изображениях
страниц и требуют распознавания или ручного просмотра.

## Какие документы проверялись

Это приказы об установлении границ территорий объектов культурного наследия.
Обычно PDF содержит сам приказ, описание объекта, схему территории и приложение
с координатами или планом. Один приказ может относиться к группе объектов, поэтому
153 документа не соответствуют 153 отдельным ОКН.

## Состояние группы 70

В группе 70 объектов без адресной привязки дом Бодунова уже имеет рабочую точку.
Поэтому фактически остаются **69 объектов без точки**. Все 70 проверены в
автоматическом этапе по номерам. Совпадений не найдено из-за сканированного вида
приказов.

## Следующий этап

1. Установить OCR-инструмент с русским языковым пакетом: Tesseract или OCRmyPDF.
2. Прогнать OCR по 153 PDF и сохранить отдельный распознанный текст, не заменяя
   исходные сканы.
3. Повторить поиск реестровых номеров и учетных номеров.
4. Для найденных документов вручную проверить название, район, дату приказа и
   приложение с границами.
5. Извлечь координаты только после проверки системы МСК, замыкания контура и
   соответствия площади.

Точечный OCR всего массива — около 964 страниц. Можно начать с документов,
которые имеют номера приказов или документы охраны, совпадающие с 69 ОКН, а
затем обработать остаток. Без OCR или ручного просмотра сканов следующий этап
автоматически выполнить нельзя.

Для экономного теста выделены первые 10 приказов, всего **59 страниц**:
[очередь OCR](../data/okn/boundary_ocr_sample_10.csv). Они не распознаны: в
окружении нет установленного Tesseract/OCRmyPDF, а попытки установить OCR-движок
через доступные менеджеры пакетов не нашли применимого установщика.

## Запуск OCR

Пайплайн находится в `scripts/okn/ocr_boundary.py`. После установки Tesseract
с русским языковым пакетом запуск первых десяти файлов:

```powershell
$env:PYTHONPATH = "tmp/okn-tools"
python scripts/okn/ocr_boundary.py --sample 10 --dpi 200
```

Для одного документа используется `--source-id`, для всего каталога — `--all`.
Результаты OCR сохраняются в `tmp/okn-ocr/`, а реестры страниц и совпадений —
в `data/okn/ocr_boundary_inventory.csv` и `data/okn/ocr_boundary_hits_70.csv`.

Первые 10 приказов проверены после распознавания: [QA-таблица](../data/okn/ocr_boundary_qa_10.csv).
На 59 страницах OCR распознал титульные части и описательный текст, но не дал
ни одного точного 15-значного номера ОКН. Номер приказа и координатные
приложения нельзя принимать по одному OCR-тексту: их нужно сверять с изображением.

## Файлы результата

- `data/okn/boundary_document_index.csv` — 153 URL и статус скачивания.
- `data/okn/evidence_sources.csv` — манифест локальных файлов и SHA-256 после
  обновления инвентаризации.
- `data/okn/evidence_inventory.csv` — размер и контрольная сумма источников.
- `data/okn/boundary_text_hits_70.csv` — результат поиска по текстовому слою
  (пустой набор совпадений).
- `data/okn/boundary_text_summary_70.csv` — сводка по каждому из 70 объектов.
- `tmp/okn-text/` — постраничные текстовые выгрузки; для приказов они пустые.

Исходные PDF находятся в `data/okn/evidence/` и не добавляются в Git из-за
размера. Принятые рабочие координаты не изменены.

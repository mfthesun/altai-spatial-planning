# Отчёт о проверке сводного датасета v1 (по чек-листу data:validate-data)

## Итог: можно использовать с оговорками

### Методика
- Единица анализа — 11 МО верхнего уровня (границы на 1.01.2025). Турочакский и Чойский районы уже стали округами с новыми кодами ОКТМО (84525, 84545). Записи с новыми кодами приведены к старым (84625, 84645), иначе эти МО выпадали из реестра МСП и ГИС ЖКХ. Ошибка была найдена и исправлена на этой проверке.
- Население: в качестве основного ряда взят ежегодник (пересчёт по ВПН-2020). Ряд из mun_demography оставлен только для динамики 2012–2022 и помечен.
- Ввод жилья: в источнике итоговый разрез переименован в 2024 г. Сначала был взят только новый разрез, из-за чего доля ИЖС выходила больше 100 %. Ошибку исправил: по каждому году берётся итоговый разрез, теперь доля ИЖС 85–99,6 %.
- Дороги: в первой сборке смешивались разрезы «всего», «твёрдое покрытие» и «усовершенствованное покрытие» (358 дублей). Исправлено, теперь это два отдельных показателя.

### Сверка расчётов (сумма по МО = итог по региону)
- Население на 1.01.2025: 210 095 = итог ежегодника ✔. На 1.01.2023: 210 769 ✔.
- Родившиеся и умершие в 2023 г.: 2 689 и 2 254 = итог ✔.
- Размещено в КСР в 2024 г.: 550 457 ≈ 550,5 тыс. в «Регионах России» ✔.
- Продукция с/х в 2024 г.: 14 837 млн = 14 837,1 ✔.
- Число КСР в 2024 г.: 491 = 491 ✔.
- Ввод жилья в 2024 г.: 223,8 тыс. м². В «Регионах России»: 1 063,7 м² на 1000 жителей × 210,8 тыс. ≈ 224,2 тыс. ✔.
- Население НП по ВПН-2020: 210 924 ≈ 210,9 тыс. ✔. У всех 247 НП есть координаты.
- Выборочная сверка с сырыми файлами: места в КСР Чемальского района (2025) — 9 697 ✔. Овцы и козы Кош-Агачского района (2024) — 103 878; это сумма трёх категорий хозяйств (11 933 + 40 122 + 51 823) ✔.
- МСП, привязанные к НП по названию: 2 599 из 2 642 (98 %).

### Найденные проблемы и что с ними сделано
1. [Высокая — исправлено] Новые коды ОКТМО для Турочака и Чои.
2. [Высокая — исправлено] Смена разреза «ввод жилья — всего» в 2024 г.
3. [Средняя — исправлено] Дубли разрезов по дорогам.
4. [Средняя — исправлено] Значение −99 999 999 (маркер «нет данных») в «Регионах России» у СФО по бедности. Заменено на пропуск.
5. [Средняя — оговорка] В рядах КСР по малым районам часты скачки больше 50 % в год (например, Чойский: +358 % в 2023 г.). Это ввод и регистрация отдельных объектов при малой базе. Пропуски: 2014, 2015 и 2020 гг. (в 2020 г. в источнике пусто по всем МО).
6. [Средняя — оговорка] В ряду инвестиций нет 2013 г. Инвестиции учтены без МСП и привязаны к месту регистрации инвестора. Пример: 83 млрд руб. в Майминском районе за 2022–2024 гг. — в основном курорт «Манжерок».
7. [Низкая] Бюджеты МО есть только до 2020 г. Поголовье по всем категориям — до 2024 г.
8. [Низкая] ВВП на душу по Kummu — модельная оценка. Использовать только для сравнения МО между собой.

### Расхождения с ранее собранными цифрами (обновить в altai_context.md)
- В Прогнозе СЭР 2025–2027 были оценки за 2024 г. Фактические данные Росстата другие. Ввод жилья: 223,8 тыс. м², а не 195. Размещено в КСР: 550,5 тыс., а не 415,4. Продукция с/х: 14,8 млрд, а не 13,3. Инвестиции: 53,8 млрд, а не 55,7. ВРП 2022 г.: 89,6 млрд, а не 91,6.
- Доля русских / алтайцев по ВПН-2020 (от указавших национальность, с учётом множественных ответов): ~53,7 % / ~37,1 %, казахи ~6,4 %. По методике Росстата (только первая национальность) значения будут немного другими.

### Обязательные оговорки для команды
- Падение населения в 2022→2023 гг. — эффект пересчёта по итогам переписи, а не реальная убыль.
- КСР — только официально учтённые средства размещения, теневой сектор не входит.
- В 2025 г. идёт муниципальная реформа (переход районов в округа), коды и границы МО меняются.

### Сверка
- Оценка численности на 1 января (новый ряд) — сумма по МО: 210 769 (2023), 210 765 (2024), 210 095 (2025). Совпадает с ежегодником ✔.
- Возрастные группы на 1.01.2024: моложе + трудоспособные + старше = всего во всех 11 МО (расхождение 0). Сумма по МО = 210 765 ✔.
- Миграция: прибывшие − выбывшие = прирост во всех 107 сопоставимых строках ✔. Внутрирегиональный прирост в сумме по МО = 0 за 2020–2023 ✔ (в 2019 г. +110 — неувязка в источнике).
- Миграционный прирост РА за 2022–2023 гг.: −361 / −439 по сумме МО. По «Регионам России»: −17 и −21 на 10 тыс. жителей, то есть ≈ −358 / −443 ✔.
- ⚠ За 2019–2021 гг. сумма по МО даёт +714 / +344 / +554, а региональные данные (пересчитанные после переписи) — минус. Ряды по МО за эти годы переписью не исправлены. Это помечено в README.
- Жилфонд на конец 2024 г.: 5 518 тыс. м² / 210,8 тыс. жит. = 26,2 м² на жителя. Региональное значение 26,3 ✔. Значение 2025 г. соответствует концу 2025 г., поэтому в сводке взят 2024 г.

### Найденные и исправленные проблемы
1. [Высокая — исправлено] В файле зарплат по каждому году лежат квартальные нарастающие итоги (январь–март, …, январь–декабрь). Сначала было взято первое попавшееся значение, например I квартал 2016 г. Исправлено: берётся январь–декабрь.
2. [Низкая] В ряду прибывших за 2012–2013 гг. есть дубли с одинаковыми значениями. Удалены, на результат не влияют.
3. [Средняя — нужна догрузка] Выгрузки Y48123005/6/7 содержат только старый ряд зарплат (по РА — 2013–2016). Актуальный ряд 2017–2026 — коды Y48423005/6/7. Неточность в моём первом списке ссылок.

### Оговорки

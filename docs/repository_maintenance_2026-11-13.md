## Очистка текущего дерева

Из текущей версии убраны 58 служебных резервных файлов с именами `*.backup-*`,
в том числе старые PNG, CSV, Python и Markdown. Их общий размер — 21 375 787 байт
(20,39 МиБ). В остальных отслеживаемых текстах ссылок на эти имена не найдено.
Данные, действующие скрипты, карты и исторические отчеты без суффикса резервной
копии сохранены. Рабочие требования AGENTS.md не изменялись.

Перед удалением создан локальный архив вне репозитория. Для каждого из 58
файлов сверены SHA-256 исходного файла и записи архива; перечень путей,
размеров и контрольных сумм сохранен рядом. Архив не публикуется повторно в Git.
Правила `.gitignore` исключают новые служебные копии и редакторские файлы `*~`.

До очистки в Git отслеживалось 349 файлов общим размером 100 242 668 байт.
Сами удаленные копии составляли 21,32 % этого объема. Точное изменение дерева
также включает небольшие изменения README и новые инструкции.

| Показатель текущей версии | До | После |
|---|---:|---:|
| Отслеживаемые файлы | 349 | 293 |
| Суммарный размер файлов, МиБ (округленно) | 95,60 | 75,22 |

Все эти версии остаются в истории коммитов, в том числе в снимке до очистки:
`ee2936e5d6c7bb220707aba05dff7f539169f168`.

Пример чтения прежнего README без изменения рабочей копии:

```bash
git show ee2936e5d6c7bb220707aba05dff7f539169f168:README.md
```

Чтобы вернуть конкретный резервный файл локально, укажите его прежний путь:

```bash
git restore --source=ee2936e5d6c7bb220707aba05dff7f539169f168 --worktree -- README.md.backup-2026-11-12
```

Возвращенный таким способом служебный файл попадает под `.gitignore`.
Список удаленных путей виден в diff коммита очистки.

## Локальное хранилище Git

Выполнено штатное уплотнение без удаления объектов и без истечения reflog:

```bash
git -c gc.reflogExpire=never -c gc.reflogExpireUnreachable=never gc --no-prune
```

Файлы `.git/` занимали 192 260 095 байт, после операции — 191 426 944 байта.
Ссылки веток/тегов и HEAD до/после совпали. Это небольшая локальная экономия,
а не удаление истории. Данные по старым PNG и резервным копиям остаются в истории,
поэтому размер нового полного клона не уменьшается на размер очищенного дерева.
Новая установка зависимостей и полный пересчет исходников не выполнялись.

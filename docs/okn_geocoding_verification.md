Для предварительного сравнения с OSM использованы опубликованные

преобразованный контур не опубликован как юридически точный GeoJSON.

геодезическую точность параметров.

## Воспроизведение

1. `python scripts/okn/fetch_evidence.py` сохраняет источники из
   `data/okn/evidence_sources.csv`. Можно передать один или несколько
   `source_id`, чтобы не повторять неудачные загрузки. Ошибка загрузки
   отмечается и возвращает ненулевой код, остальные источники сохраняются.
2. `python scripts/okn/extract_evidence.py` извлекает текст по страницам
   в `tmp/okn-text/`. Нужен PyMuPDF. Сканированные страницы требуют
   визуального чтения, автоматического OCR этот шаг не делает.
3. `python scripts/okn/verify_evidence_geometry.py` проверяет площадь,
   ребро, замыкание контура, предварительное попадание точки OSM,
   адрес здания и перевод координат научной публикации. Нужен pyproj
   из зависимостей проекта.
4. `python scripts/okn/build_verified_geocoding.py` пересобирает рабочие
   CSV и GeoJSON стандартной библиотекой Python. Проверяет уникальность,
   сохранность A/B и дополнение только записей X.
5. `python scripts/okn/summarize_evidence.py` создает таблицу проверки,
   индекс приказов и [опись источников с SHA-256](../data/okn/evidence_inventory.csv).

PDF остаются локальными: они исключены существующим правилом `*.pdf`.
Для восстановления сохранены URL и контрольные суммы. Исторические карты
и проверка чисел всего проекта этим этапом не пересобирались.

Для текущей временной установки инструментов перед шагами 2–3 в PowerShell:
`$env:PYTHONPATH = 'tmp/okn-tools'`. Использованы PyMuPDF 1.28.2 и pyproj 3.8.0.
Зависимости проекта и системная установка Python не изменены.

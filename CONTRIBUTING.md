# Как подключиться к работе

Репозиторий открыт: читать, скачивать и предлагать правки может любой. Задачи команды — в разделе **Issues**, у каждой есть исполнитель и метка роли.

## Самый простой способ (без установки чего-либо)
1. Зарегистрируйтесь на GitHub и пришлите свой логин Денису — он добавит вас в соавторы (тогда можно сохранять правки сразу в репозиторий).
2. Откройте нужный файл → карандаш ✏️ → правка → **Commit changes**. Для новых файлов: **Add file → Upload files**.
3. Для расчётов нажмите **Code → Codespaces → Create codespace**: в браузере откроется готовая среда с Python и всеми библиотеками (`requirements.txt` ставится сам).
4. Блокнот доступности больниц открывается в Google Colab кнопкой в README.

## Если вы не в соавторах
Нажмите **Fork**, внесите правки в свою копию и откройте **Pull request** — Денис примет его.

## Правила
- Один pull request или коммит — одна задача; в описании ссылка на issue (`#3`).
- Данные кладём в `data/`, тексты и выводы — в `docs/`, код — в `scripts/`.
- У каждой цифры на слайде — источник (файл в репозитории или ссылка).
- Большие сырые архивы (больше 50 МБ) в репозиторий не кладём — только ссылку в `data/raw/README.md`.
- Числа из СТП берём из текста docx (`data/stp_extracted/`), а не из распознанного скана.

## Структура
См. `README.md`. Контекст по региону — `docs/altai_context.md`, договорённости — `CLAUDE.md`.

## Проверка чисел
У каждого числа в слайдах должен быть источник. Числа из данных репозитория пересчитывает `python3 scripts/check_numbers.py`: код выхода 0 — всё сходится. Реестр источников ведётся в `docs/numbers_check.md`. Добавили новое число — добавьте его туда же.

## Облачная среда Claude Code
Для работы с нейросетью на claude.ai/code заведена отдельная среда проекта:
- **Сеть:** полный доступ. Нужны PyPI, `maps.mail.ru` (зеркало Overpass) и `copernicus-dem-30m.s3.amazonaws.com` (рельеф).
- **Переменные:** `OVERPASS_URL=https://maps.mail.ru/osm/tools/overpass/api/interpreter`, `OVERPASS_TIMEOUT=900`.
- **Setup script:** `cd altai-spatial-planning && bash scripts/cloud_setup.sh`. Скрипт ставит `requirements.txt`, это около полутора минут.

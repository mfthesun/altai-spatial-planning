# Объекты культурного наследия Республики Алтай

## Промежуточные результаты поиска координат

Состояние на 11 ноября 2026 года. Сводка объединяет аудит исходных данных,
сопоставление с OSM, проверку источников и проход по текстовому слою ГИКЭ.

ОКН — объект культурного наследия. ЕГРОКН — Единый государственный реестр
объектов культурного наследия. ГИКЭ — государственная историко-культурная
экспертиза. СТП — схема территориального планирования. OSM (OpenStreetMap) —
открытая картографическая база. OCR — распознавание текста на изображениях.
МСК — местная система координат. ООПТ — особо охраняемая природная территория.

## Текущее состояние данных

В выгрузке ЕГРОКН по Республике Алтай 288 объектов. Исходное геокодирование
дало 76 реестровых точек и 91 привязку к центру населенного пункта.
Без координат оставался 121 объект.

В ходе проверки добавлены **8 рабочих привязок**. Сейчас отдельный рабочий
слой содержит **175 объектов с точкой и 113 без точки**.

| Уровень привязки | Объектов | Содержание |
|---|---:|---|
| A | 76 | Координаты из исходной выгрузки ЕГРОКН |
| B | 91 | Центр населенного пункта, определенного по адресу |
| C | 2 | Точки OSM, проверенные по адресу или документу территории |
| D | 6 | Координаты из актов, муниципальных материалов и научной публикации |
| Без точки | 113 | Принятая рабочая привязка отсутствует |
| **Всего** | **288** | |

175 точек имеют разную точность. Центр населенного пункта и ориентир одного
кургана не устанавливают положение всей территории ОКН. Новые точки C/D
предназначены для картографического анализа с оговорками об источниках.

Результаты собраны в отдельный рабочий набор. Исходные данные сохранены.

## Объем выполненной проверки

Первоначальный аудит охватил все 121 запись без точки. Для 120 найдено
соответствие в СТП по номеру, для одной сначала использовалось название.
Кызыл-Телань-1 впоследствии подтвержден в дополнительном документе по точному
реестровому номеру. В официальном перечне инспекции на 01.01.2018 найдены
все 117 федеральных объектов исходного остатка. Это подтверждает идентичность
записей, но не их актуальный правовой статус на 2026 год.

Для сопоставления с OSM использована выборка из 2102 объектов. Получены
11 пар кандидатов для 7 ОКН. Совпадения проверялись по названию, району,
адресу и доступным первоисточникам. Само совпадение названия не считалось
основанием для добавления точки.

По группе из 51 объекта с именными или топонимическими подсказками выполнены
102 отдельных поисковых запроса. Для 37 объектов прочитаны дополнительные
первоисточники. После этого прохода у 7 объектов группы есть рабочая точка,
44 остаются без нее. Эта группа входит в исходные 121 и не прибавляется к ним.

### ГИКЭ без OCR

В последнем проходе проверен текстовый слой **49 PDF, 6068 страниц** из раздела
ГИКЭ инспекции. Проверялись 118 объектов: исходные 121 за вычетом дома Бодунова,
Калбак-Таша и Тархатинского комплекса, уже получивших точки на первом этапе.
Пять объектов из этих 118 получили точки при последующей проверке группы 51.
Все нынешние 113 объектов без точки охвачены проходом по ГИКЭ.

| Результат проверки роли упоминаний | Объектов |
|---|---:|
| Документы непосредственно по объекту | 6 |
| Точный номер в обзоре других территорий | 3 |
| Совпадение названия без подтвержденной идентичности | 14 |
| Совпадений в доступном тексте нет | 95 |
| **Всего** | **118** |

Документы по шести объектам относятся к Елангашу, Туэкте, Пазырыку, Катанде,
Соузге и Кумжулу. Катанда и Пазырык уже изучались ранее. Для Кумжулу
соответствие установлено по полному названию и местоположению в акте до
включения в реестр. Остальные пять связаны с документами по точному номеру.

Новых точек этот проход не добавил. На 932 страницах извлекается мало русского
текста. Среди них могут быть сканы таблиц, схемы, фотографии и подписи.
Отсутствие текстового совпадения не исключает сведений в графических приложениях.
Два DOC со сводками обсуждения не входили в PDF-проход.

## Следующие шаги

1. Сверить выписку Соузги и окончательный документ по Кумжулу. Проверить системы
   координат Кумжулу и Пазырыка перед преобразованием границ.
2. Прочитать графические приложения ГИКЭ Елангаша и Туэкты. При необходимости
   применить OCR к выбранным страницам с последующей проверкой цифр по изображению.
3. Продолжить проверку отдельных приказов о границах. В каталоге 153 ссылки,
   на первом этапе просмотрены заголовки трех приказов. Этот каталог целиком
   еще не разобран.
4. Подтвердить идентичность научных кандидатов и разрешить конфликт Кара-Бома.
   Для остальных объектов искать паспорта, документы территории и архивные планы.

## Ограничения результата

Проверены согласованность итоговых чисел, охват всех 113 оставшихся объектов
проходом по ГИКЭ и сохранность прежних 167 точек. Полнота архивного поиска и
геодезическая точность новых привязок не подтверждены. OCR в последнем
проходе не применялся.

Документы и исторические перечни использовались для установления идентичности
и положения объектов. Эта работа не заменяет проверку актуального правового
статуса и официальное установление границ территории ОКН.

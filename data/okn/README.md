# ОКН из ЕГРОКН — вырезка по Республике Алтай (03.11.2026)

## Источник

Выгрузка ЕГРОКН `data-70-structure-16.csv` (516 МБ, вся Россия, 163 701 запись; получена
Денисом 28.10.2026). Вырезка сделана блокнотом `scripts/okn/egrokn_altai_cut.ipynb`:
фильтр по `Id-Регион = 04`.

## Что внутри

| Файл | Содержимое |
|---|---|
| `egrokn_altai.csv` | 288 объектов: название, категория, район, адрес, рег. номер, документ о постановке на охрану, координаты (где есть) |
| `egrokn_altai_points.geojson` | 76 точек с координатами (поле «На карте» выгрузки, GeoJSON Point, EPSG:4326) |
| `okn_by_mo_egrokn.csv` | сводка по районам: федеральные / региональные / местные |

Состав: **117 федеральных + 170 региональных + 1 муниципальный = 288**.
Выявленные объекты (318 по приказам и 2 130 по перечню 2018) в ЕГРОКН не входят —
см. `data/stp_extracted/okn/`.

## Геокодирование (03.11.2026, `scripts/okn/geocode_okn.py`)

| Уровень | Объектов | Что это |
|---|---|---|
| A: точка из ЕГРОКН | 76 | координаты поля «На карте» выгрузки |
| B: центр НП по адресу | 91 | НП восстановлен из адреса офлайн-сопоставлением с перечнем 247 НП; точность — до населённого пункта |
| X: без точки | 121 | адреса нет (федеральная археология) или НП адреса отсутствует в перечне (Камышла/Кумжулу, Курумда — ликвидированные и малые НП) |
| **Итого с координатами** | **167 из 288** | `egrokn_altai_geocoded.csv` (все 288, с уровнем) и `egrokn_altai_points_all.geojson` (A+B, свойство «качество») |

Оговорки: уровень B ставит объект в центр НП, а не на место объекта; Overpass из среды
недоступен (overpass-api.de — 406, зеркало mail.ru — обрыв TLS), поэтому сопоставление
с OSM (historic=*) не выполнялось — 117 федеральных объектов без адреса остаются без точки.
Файл `egrokn_altai_points.geojson` (76 точек уровня A) сохранён как раньше.

Разбор всех 121 объектов уровня X от 10.11.2026: [сводка](../../docs/okn_unresolved_audit.md),
[построчная таблица](egrokn_altai_unresolved_audit.csv). У 118 записей адрес пустой
(117 федеральных и дом Бодунова), у трех есть неполное или несопоставленное адресное
описание. Адрес дома Бодунова найден в СТП. Координаты этим разбором не изменены.

Пробное [сопоставление с OSM](../../docs/okn_osm_matching.md) от 11.11.2026:
четыре кандидата по имени и району, ориентир Камышлы и конфликт адреса дома
Бодунова. Кандидаты хранятся отдельно, основной геослой не изменен.

Проверка первоисточников 11.11.2026: [первый этап](../../docs/okn_geocoding_verification.md)
и [индивидуальный проход по 51 объекту](../../docs/okn_named51_review.md).
Отдельный рабочий слой `egrokn_altai_working.csv` / `.geojson` содержит **175 точек**:
исторические 167, две привязки C и шесть D с указанием источника и точности.
Осталось **113 без точки**. Таблица результатов всех 51 — `named51_review.csv`,
состояние исходных 121 записей — `okn_source_checks.csv`.
Уровни C/D не равны точным координатам ЕГРОКН и не задают границы территорий.
Исходные слои сохранены.

## Сверка с СТП (Том 3)

Проверка ГИКЭ без OCR от 11.11.2026: [отчет](../../docs/okn_gike_text_review.md),
[118 строк результатов](gike_text_review_118.csv). Проверен текстовый слой 49 PDF
(6068 страниц); документы непосредственно по шести объектам. Вершины Кумжулу
и Соузги сохранены в исходной системе координат, новые точки не добавлены.


| Категория | СТП | ЕГРОКН | Комментарий |
|---|---|---|---|
| Федеральные | 118 | 117 | 2 объекта ЕГРОКН не связались по рег. номеру с реестром СТП (Кызыл-Телань-1, «Группа курганов»), 1 федеральный СТП в ЕГРОКН не найден |
| Региональные | 170 | 170 | совпадает |
| Местные | 0 | 1 | «Территория бывшего села Кумжулу (Камышла)», Шебалинский район — новый объект |

Район у 115 федеральных восстановлен по реестру СТП (совпадение по регистрационному
номеру), у остальных — по адресу; у 3 объектов район не определён.

## Оговорки

- **Координаты есть только у 76 из 288** — поле «На карте» выгрузки заполнено не для всех.
  Остальные можно догеокодировать по адресам/ФИАС или взять из OSM (historic=*).
- Колонка «Тип ОКН» в выгрузке пустая; вид объекта — в `stp_extracted/okn/`.
- Доли ЮНЕСКО все «нет» — объект ЮНЕСКО «Золотые горы Алтая» покрывает территории
  заповедников, а не отдельные ОКН.
